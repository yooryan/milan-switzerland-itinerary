# 米兰与瑞士｜冬夏十日行程

香港往返米兰、意大利与瑞士自驾的交互式行程计划书。提供 1–2 月冬季和 5–6 月春末初夏两条路线，含总览地图、每日活动、餐饮建议与 Coop 自炊安排。

## 使用

直接打开 `index.html`，或通过 GitHub Pages 访问。页面无需构建，照片与地图已内嵌。个人备注、勾选和预订记录仅保存在当前浏览器；可用“保存副本”导出含个人记录的 HTML。

## GitHub Pages

在仓库 Settings → Pages 中选择 **Deploy from a branch**，分支设为 **main**，目录设为 **/(root)**，点击 Save。`.nojekyll` 用于直接发布静态文件。

## 图片与资料

户外照片按路线月份筛选：冬线 1–2 月，夏线 5–6 月；室内建筑照片单独注明。每张照片的作者、原始出处、拍摄日期及许可均保留在页面“风景摄影”和大图详情中。各照片适用其各自许可，并非整站统一授权。图片为历史实拍，不能替代出行日期的天气和运营查询。

本页是个人旅行规划，不是旅行社产品；交通、住宿、门票与餐饮需自行核实和预订。
